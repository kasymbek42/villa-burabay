# Вилла де Бурабай — сайт зоны отдыха

Прототип (Этап 0 по [PRD.md](PRD.md)) официального сайта зоны отдыха в Бурабае (Боровое), Казахстан.

Сайт работает без сборки и без бэкенда: чистые HTML, CSS и JavaScript. Это сделано намеренно — прототип нужно показывать заказчику, а не разворачивать.

## Запуск

Любой статический сервер в корне проекта:

```bash
python -m http.server 5173
```

Затем откройте http://localhost:5173

Файл `index.html` открывается и напрямую из файловой системы — внешних запросов, кроме шрифтов Google, нет.

## Структура

```
index.html        разметка всех секций
css/main.css      стили, природная палитра, mobile-first
js/i18n.js        словари RU / KZ / EN и переключатель языка
js/data.js        демо-данные: номера, досуг, занятость, база знаний чата
js/app.js         логика: календарь, бронь, расчёт аванса, чат, карта
PRD.md            исходное техническое задание
```

## Что это именно прототип

Заменяется на Этапе 1 (MVP):

- **Занятость номеров** — `DATA.isRoomBusy()` считает детерминированную псевдослучайную загрузку по id номера и дате. Нужен реальный календарь из админ-панели.
- **Оплата** — `setTimeout` вместо платёжного шлюза. Нужен Kaspi Pay / EPay (Halyk), для иностранных карт Stripe.
- **WhatsApp** — модальное окно вместо отправки. Нужен WhatsApp Business API с шаблонами, одобренными Meta (закладывать время на модерацию).
- **Брони** — хранятся в `localStorage` браузера. Нужна база и панель администратора.
- **ИИ-помощник** — поиск по ключевым словам. Нужна LLM с контекстом зоны отдыха и переключением на оператора.
- **Аналитика** — функция `track()` пишет в консоль при `?debug` в адресе. Нужен Google Analytics или Яндекс.Метрика.

## Настройки

Доля аванса (PRD 6.5) меняется одной строкой в `js/data.js`:

```js
prepayRate: 0.3,
```

Координаты и контакты — там же, в `DATA.venue`. От них строятся ссылки на все три картографических сервиса.

## Открытые вопросы

Раздел 12 PRD остаётся открытым: финальное название и координаты, точные цены по сезонам, политика отмены, состав номерного фонда. Все эти данные в прототипе — примеры из обсуждения, собранные в `js/data.js` так, чтобы их правка не затрагивала логику.
